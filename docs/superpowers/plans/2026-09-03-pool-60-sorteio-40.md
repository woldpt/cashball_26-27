# Pool 60 → Sorteio 40 por Sala Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Base de dados template com 60 equipas (12×5) e cada sala nova sorteia 8 por divisão (40 activas), com Sporting/Porto/Benfica sempre na D1 e Juventude SC sempre na D4, para dar variedade entre salas sem alterar salas existentes.

**Architecture:** `base.db` passa a 60 equipas (seed lê `all_teams.json` com 60). `gameManager.ts#getGame()` após `fs.copyFileSync(base.db → game_<ROOM>.db)` executa filtragem transaccional por divisão dentro da DB da sala: mantém 8 por divisão via amostragem sem reposição com fixos garantidos, apaga as 20 excedentes e cascata (`players`, `managers` órfãos). Nenhuma coluna nova; `fixtures_hash` actualizado força re-seed automático do template via `ensureSeeded.js`. Salas existentes nunca tocadas.

**Tech Stack:** Node.js 20, TypeScript (tsx), SQLite3 (`sqlite3` verbose, WAL, `busy_timeout=5000`), `server/db/seed.js` (JS puro), `server/scripts/fetchZerozeroSquads.ts` (scraping `zerozero.pt` `#team_squad`), `server/db/schema.sql`, `gameManager.ts` (room lifecycle).

**Spec:** Pedido do utilizador 2026-09-03: 60 no pool (listas exactas fornecidas), 40 activas por sala (8×5), fixos D1=Sporting/Porto/Benfica, D4=Juventude SC. Este plano é a spec executável.

function shuffle<T>(arr: T[]): T[] {
  const a = [...arr];

Pseudo-código completo a inserir (TypeScript, dentro de `getGame` após `fs.copyFileSync`):

```ts
    // Pool 60→40 — amostragem síncrona bloqueante com better-sqlite3 se disponível, fallback sqlite3
    try {
      const BetterSqlite = (() => { try { return require("better-sqlite3"); } catch { return null; } })();
      if (BetterSqlite) {
        const tmp = new BetterSqlite(dbPath);
        const rows: Array<{id:number, name:string, division:number}> = tmp.prepare("SELECT id, name, division FROM teams").all();
        const byDiv: Record<number, typeof rows> = {1:[],2:[],3:[],4:[],5:[]};
        for (const r of rows) byDiv[r.division]?.push(r);
        const FIXED: Record<number,string[]> = {1:["Sporting","Porto","Benfica"],4:["Juventude","Juventude SC"]};
        const keepIds: number[] = [];
        for (let d=1; d<=5; d++) {
          const pool = byDiv[d] || [];
          const fixedNames = FIXED[d] || [];
          const fixed = pool.filter(t => fixedNames.includes(t.name));
          const rest = pool.filter(t => !fixedNames.includes(t.name));
          const need = 8 - fixed.length;
          if (pool.length !== 12) console.warn(`[gameManager] D${d} pool inesperado: ${pool.length} (esperado 12)`);
          if (need < 0) throw new Error(`Fixos a mais na D${d}`);
          const sampled = shuffle(rest).slice(0, need);
          keepIds.push(...fixed.map(t=>t.id), ...sampled.map(t=>t.id));
        }
        const keepSet = new Set(keepIds);
        const dropIds = rows.filter(r=>!keepSet.has(r.id)).map(r=>r.id);
        if (dropIds.length !== 20) console.warn(`[gameManager] drop esperado 20, obtido ${dropIds.length}`);
        const tx = tmp.transaction(() => {
          if (dropIds.length) {
            const ph = dropIds.map(()=>'?').join(',');
            tmp.prepare(`DELETE FROM players WHERE team_id IN (${ph})`).run(...dropIds);
            tmp.prepare(`DELETE FROM teams WHERE id IN (${ph})`).run(...dropIds);
            // managers órfãos
            tmp.prepare(`DELETE FROM managers WHERE id NOT IN (SELECT manager_id FROM teams WHERE manager_id IS NOT NULL)`).run();
            // limpar FKs órfãs se existirem (matches/cup vazios em base, mas por segurança)
            tmp.prepare(`DELETE FROM player_skill_snapshots WHERE player_id NOT IN (SELECT id FROM players)`).run();
          }
          tmp.prepare(`INSERT OR REPLACE INTO game_state (key,value) VALUES ('pool_sampling', ?)`).run(JSON.stringify({kept: keepIds.length, dropped: dropIds.length, at: new Date().toISOString()}));
        });
        tx();
        tmp.close();
        console.log(`[gameManager] Sala ${roomCode}: pool 60→40 filtrado (keep ${keepIds.length}, drop ${dropIds.length})`);
      } else {
        // fallback: se better-sqlite3 não instalado, log e não filtrar (comportamento degradado)
        console.warn(`[gameManager] better-sqlite3 ausente — pool 60→40 não aplicado para ${roomCode} (instalar better-sqlite3)`);
      }
    } catch (e) {
      console.error(`[gameManager] Falha ao filtrar pool 60→40 para ${roomCode}:`, e);
    }
```

Notas de implementação (importantes):
